# 진성 DB 닫힌 고리 데스크 (시제품)

광고로 들어온 상담 신청(리드)이 **결번 · 중복 판정 → 상담 메신저로 첫 응대 → 상담 결과(예약 · 내원 · 계약) → 광고 매체로 결과 되돌리기**까지 한 장의 리드 카드로 흐르고, 광고주는 신청 1건당 광고비가 아니라 **내원 1명당 광고비**를 보는 시제품입니다.

| 화면 | 누가 | 하는 일 |
|---|---|---|
| 상담원 화면 | 광고주 쪽 상담 담당자 | 리드 카드 · 첫 응대 타이머 · 템플릿 메시지 · 상태 바꾸기 · 매체 되돌리기 대기열 |
| 광고주 리포트 · 요금 계산기 | 광고주 · 대행사 마케터 | 광고비 → 리드 → 유효 리드 → 예약 → 내원 → 계약 깔때기, 단가 비교, 요금 3단 매출 계산 |

- 데이터는 모두 가상입니다. 실제 회사 · 고객 · 전화번호 · 가격이 아닙니다. 매체로 실제 전송하지 않습니다.
- 광고 대행사 웹 플랫폼 기획자 지원용 개인 프로젝트입니다. 문서 초안 · 코드는 Claude(AI)와 함께 만듭니다.
- 상태: 화면 2개 구현 · 시험 53개 통과(2026-11-25). 공개 전.

## 실행법

빌드 없는 정적 페이지입니다(ADR 0001). Node 20 이상 · Python 3이 있으면 됩니다.

```
node --test tests/
python -m http.server 8798 --directory site
```

- 두 번째 명령 뒤 http://localhost:8798 을 엽니다.
- 시연 순서: [docs/flows.md](docs/flows.md) F6.
- 시간은 2026-11-25 10:00으로 고정돼 있습니다(ADR 0004). 새로고침하면 리드는 시작 상태로 돌아갑니다(ADR 0002).
- 공개 전에는 저장소 밖 스크립트로 회사 이름 검사를 따로 합니다(ADR 0003).
