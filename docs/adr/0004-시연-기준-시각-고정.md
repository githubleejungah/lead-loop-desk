# ADR 0004 — 시간 계산은 고정된 시연 기준 시각으로

- 상태: 승인 · 2026-11-25 (설계 승인)
- 근거: 요구 A3 · A4, AC-18~21 · AC-23 · AC-26

## 결정

첫 응대 타이머 · 28일 · 90일 · 재연락 일정은 실제 현재 시각이 아니라 `seed.DEMO_NOW`(2026-11-25 10:00, 한국 시간) 하나로 센다. 화면 시간은 저절로 흐르지 않는다. 상담원 행동 시각도 이 값으로 기록한다.

## 이유

- 언제 열어도 M01 '남은 40분', T06 '주의', M20 '초과', G11 '미응대'가 같은 모습으로 나와야 시연 · 포트폴리오 캡처가 맞는다.
- 시험이 시각에 따라 흔들리지 않는다.

## 대안

| 대안 | 기각 이유 |
|---|---|
| 실제 현재 시각 | 며칠 뒤 열면 모든 리드가 '미응대' · '28일 넘음'이 됨 |
| 현재 시각 + 시작 데이터를 열 때마다 당겨 옴 | 타이머가 흐르며 시연 숫자가 매번 달라짐 |
| '시간 +10분' 버튼 | 범위가 늘고 끝 조건이 하나 더 생김. 다음 판으로 미룸 |

## 결과

- 화면에 "시연 기준 시각 2026-11-25 10:00" 1줄을 보인다.
- 실제 서비스라면 서버 시각을 쓴다(범위 밖).
