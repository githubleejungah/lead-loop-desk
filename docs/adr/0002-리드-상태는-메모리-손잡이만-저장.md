# ADR 0002 — 리드 상태는 메모리에, 계산기 손잡이 9개만 저장

- 상태: 승인 · 2026-11-25 (설계 승인)
- 근거: 요구 A1 · A2 · A5, AC-41 · AC-42 · AC-51

## 결정

상담원이 바꾼 리드 상태는 브라우저 메모리에만 둔다. 새로고침하면 시연 시작 상태로 돌아간다. 요금 계산기 손잡이 9개(정수)만 localStorage `lld:v1:knobs`에 저장한다. 깔때기 · 단가 · 연 매출은 저장하지 않고 매번 계산한다.

## 이유

- 심사자마다 같은 시작 상태에서 시연 사례 1 · 2를 다시 볼 수 있다.
- 가상이라도 이름 · 번호가 든 리드를 브라우저에 남기지 않는다.
- 계산 결과를 저장하지 않으면 리드 상태와 리포트 숫자가 어긋날 길이 없다.
- 계산기 값은 담당자가 바꿔 둔 가정을 다시 볼 수 있게 남긴다.

## 대안

| 대안 | 기각 이유 |
|---|---|
| 리드 상태도 저장 | 시연이 사람마다 달라지고 '처음으로' 버튼이 필요해짐. 저장할 이유가 작음 |
| 아무것도 저장 안 함 | 계산기 가정을 바꿔 보는 담당자 경험이 끊김 |
| 단가 · 매출을 저장 | 리드 상태와 어긋날 수 있음 |

## 결과

- 새로고침하면 리드는 시작 상태, 계산기는 마지막 저장값으로 열린다.
- 저장이 막힌 브라우저에서는 계산기도 기본값으로 돌아간다(안내 1줄, AC-51).
