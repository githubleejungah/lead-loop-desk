# ADR 0001 — 정적 페이지와 가상 데이터

- 상태: 승인 · 2026-11-25 (요구 확정 · 설계 승인)
- 근거: 이전 시제품들과 같은 방식, 지원 마감(2026-11-28)

## 결정

GitHub Pages 정적 페이지로 만든다. 가상 리드 · 광고비 · 요금 가정값을 파일 하나에 넣고, 화면에서 바꾼 값은 보는 사람 브라우저에만 둔다. 서버 · 외부 API · 실제 메시지 발송 · 실제 매체 전송은 쓰지 않는다.

## 이유

- 심사자가 링크를 열 때마다 같은 시연이 나와야 한다.
- 전화번호 같은 개인정보 · 키 관리 · 요금 위험이 없다.
- 화면 2개 범위를 3일 안에 끝낼 수 있다.

## 대안

| 대안 | 기각 이유 |
|---|---|
| 작은 서버 + DB + 실제 알림톡 | 배포 · 비용 · 개인정보 부담, 마감 안에 어려움 |
| 화면 설계서(그림)만 | 상태 규칙 · 판정 · 단가 계산이 맞는지 돌려 볼 수 없음 |
| 스프레드시트 계산기 | 상담원 화면의 상태 변화가 리포트 숫자로 이어지는 것을 보여 줄 수 없음 |

## 결과

- 상태 · 판정 · 단가 · 매출 규칙은 순수 함수로 만들어 시험한다.
- 숫자는 가상 · 가정이라 성과가 아니다. 화면과 문서에 그렇게 적는다.
